# Phase 1 — Core CRM (MVP): slice plan

Goal (blueprint section 27): your own company (Tenant #1) runs sales on UBOS instead of spreadsheets.
Everything is built and tested **locally** (no hosting spend). Each slice ends with tests and a local commit.

| Slice | Scope | Status |
|---|---|---|
| 1.1 Sign-in & security | Sign in with email / username / mobile + password, **Continue with Google**, **Continue with Microsoft**, **one-time email code**; httpOnly cookie sessions with refresh-token rotation and theft detection; idle timeout; device list & remote sign-out; TOTP two-factor (mandatory per role); IP allow-list; lockout; password change; admin reset/unlock; CSRF protection; organization Security Policy page | **Done** (36 e2e checks) |
| 1.2 Users, roles & org structure | Users page (add with email invite, edit, deactivate/reactivate, reset password, unlock), multiple roles per person per workspace or organization-wide (with optional end date), custom roles with a permission × scope matrix + Deny, duplicate/delete roles, protected Organization Admin, anti-escalation (you can only grant what you have), last-admin protection, branches → departments → teams linked to workspaces, reporting lines with loop check, plan licence limit | **Done** (30 e2e checks) |
| 1.3 Workspace settings | Per business line: several pipelines; stage editor (rename, add, reorder, Open/Won/Lost, safe delete); custom lead fields (11 types incl. dropdown, multi-select, date, amount; required; archive; order; key never changes); lead sources & lost reasons lists; lost reason asked when a lead is lost; Add lead form built from the workspace fields; business-line heads can manage their own workspace only; archive/restore workspace | **Done** (26 e2e + 6 unit checks) |
| 1.4 Customer Master | One customer per person across all business lines; new leads auto-link by mobile, alternate mobile or email (new number kept as alternate); one active customer per mobile enforced in the database; PAN stored encrypted with keyed-hash matching, only last 4 shown, never in audit; duplicate suggestions (exact: same email / PAN / number; possible: similar name via trigram search) with "not the same person"; merge (leads, packages, numbers and missing details move; sticky RM kept) with full undo; Customers list, Customer 360° (KPIs, enquiries across business lines, timeline, merged records) | **Done** (30 e2e checks) |
| 1.5a Lead work & bulk actions | Bulk upload (CSV / Excel, 5-step wizard: column matching, duplicate & error preview, assignment choice, error report, upload history); bulk Assign (one person or round-robin) / Change stage (lost reason) / Change status / Remark / Follow-up; lead status (Hot / Warm / Cold…) separate from stage; call dispositions with "customer reached" flag; remarks; follow-ups with today / overdue counters; lead detail page with stage journey bar, Log-call panel and customer-journey timeline; assignment rules per workspace (round-robin pool, fixed, creator) with sticky Primary RM; read-only roles never get leads; 36-integration catalogue grouped by category | **Done** (37 e2e + 5 unit checks) |
| 1.5b Settings & admin (from reference screens) | **Lead stages board**: Initial / Active / Closed (Won, Lost + lost reasons) columns, colours, drag-to-reorder, default stage. **Fields settings**: choose the Lead ID (unique identifier: mobile or email), primary display fields (H1 / H2), field search, type filter, active / archived view, created / modified dates. **Call feedback**: default outcome when a call connects, drag-to-reorder, edit / delete menu. **Custom actions**: named forms with a code and a score (e.g. "Course Details"), run from a lead, answers saved on the lead timeline, archive / duplicate. **User management**: filters (role, 2FA, status, licence), export, bulk add users from Excel, pagination, licence column. **Billing & licences**: plans (quarterly / annual), add-on services, order & transaction history (payment gateway in test mode later — no spend). **Extras for flexibility**: mandatory fields per stage, stage SLA timer ("in stage for 3 days" warning), auto-actions on stage change (set status, create follow-up), lead scoring from custom-action scores, field-level visibility per role | Next |
| 1.5c Views & export | Saved views per user (filters + columns), export with field masking and per-role row limits, email / in-app reminders for follow-ups | Planned |
| 1.6 Dashboards & analytics v1 | Separate dashboards per level (company, business line, team, user) and role; KPI tiles with trends, funnel, trend lines, source ROI, leaderboards, call heatmap, drill-down to leads, pipeline-weighted forecast and month-end projection; saved custom dashboards; scheduled digests. Details: ROADMAP.md → Dashboards & analytics | Planned |
| 1.7 Integrations (free to test locally) | Website/API inbound webhook with secret + source→workspace mapping; Google Sheets import via published-CSV link (OAuth version later) | Planned |
| 1.8 Platform Console basics | Tenant detail, change plan, entitlement overrides, platform staff users & 2FA | Planned |
| 1.9 Upgrades | Next.js 16 and Prisma 7 (clears current `npm audit` advisories) | Planned |

Out of scope for Phase 1 (later phases): calling, WhatsApp, billing, HRMS, AI.
